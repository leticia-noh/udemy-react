Este repositório contém os códigos exercícios e projetos criados durante o curso **React - The Complete Guide (incl. Next.js, Redux)** da Udemy, com auxílio do instrutor Maximilian Schwarzmüller.  
Durante o curso, foram estudados os principais conceitos e recursos do React, incluindo componentes, props, hooks, estilização de componentes, Tailwind CSS, debugging, refs, portals, contexts, requisições HTTP, formulários, Redux e roteamento. Os conteúdos foram abordados por meio de definições conceituais, exemplos de código e implementações práticas, explorando a construção de interfaces dinâmicas, o gerenciamento de estado, a comunicação com APIs e a navegação entre diferentes páginas da aplicação. 
  
Algumas anotações teóricas com exemplos de código podem ser encontradas no link a seguir: [Notion](https://app.notion.com/p/React-36441ad4fce380c6938cfed0190ae12a?source=copy_link)
